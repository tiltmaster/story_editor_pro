# Camera scenes

Generated with the built-in image generation tool on 2026-09-11 for this project.

- `sunset_terrace.png`: Mediterranean sunset, limestone terrace, sea, natural portrait perspective.
- `night_waterfront.png`: blue-hour waterfront skyline and open rooftop terrace.

Both source files are **941 × 1672** pixels. The generator was requested to produce 2160 × 3840, but returned these smaller dimensions. These are not native 4K assets. No artificial resizing is represented as additional detail.

The original photographic pixels are composited using the real person mask on both platforms. Android keeps scene resolution independent of the lower-resolution segmentation mask; iOS uses Core Image cover fitting. No people or lettering are present in these scene assets.
